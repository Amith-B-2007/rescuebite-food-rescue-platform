1. Java PriorityQueue<FoodBatch> Engine (`FoodBatch.java`)

Min-Heap comparator implementation ranking batches by expiry urgency & perishability factor.

src/main/java/com/foodrescue/model/FoodBatch.java 
public class FoodBatch implements Comparable<FoodBatch> {
    private String id;
    private String donorName;
    private Instant expiryTime;
    private int servings;
    private String category;
    private String status; // AVAILABLE -> CLAIMED -> EN_ROUTE -> PICKED_UP -> DELIVERED

    public double getPriorityHeapKey() {
        double minutesLeft = Duration.between(Instant.now(), expiryTime).getSeconds() / 60.0;
        double perishabilityMultiplier = switch (category) {
            case "COOKED_MEALS", "EVENT_BUFFET" -> 0.90; // Most perishable
            case "DAIRY_PACKAGED" -> 0.95;
            case "BAKERY" -> 1.00;
            default -> 1.05;
        };
        double volumeBonus = Math.min(10.0, servings / 25.0);
        return (minutesLeft * perishabilityMultiplier) - volumeBonus;
    }

    @Override
    public int compareTo(FoodBatch other) {
        // Active unclaimed batches always precede claimed/completed ones in Min-Heap
        boolean thisActive = "AVAILABLE".equals(this.status) && getSecondsUntilExpiry() > 0;
        boolean otherActive = "AVAILABLE".equals(other.status) && other.getSecondsUntilExpiry() > 0;
        if (thisActive != otherActive) return thisActive ? -1 : 1;

        return Double.compare(this.getPriorityHeapKey(), other.getPriorityHeapKey());
    }
}

2. Haversine Formula & Expiry Feasibility (`DistanceCalculator.java`)

Computes great-circle distance between Donor & NGO coordinates and verifies arrival before food expiry.

src/main/java/com/foodrescue/util/DistanceCalculator.java 
public class DistanceCalculator {
    private static final double EARTH_RADIUS_KM = 6371.0;
    private static final double AVERAGE_CITY_SPEED_KMH = 28.0;

    public static double calculateHaversineDistanceKm(
            double lat1, double lon1, double lat2, double lon2) {
        double dLat = Math.toRadians(lat2 - lat1);
        double dLon = Math.toRadians(lon2 - lon1);
        double a = Math.pow(Math.sin(dLat / 2), 2)
                 + Math.cos(Math.toRadians(lat1)) * Math.cos(Math.toRadians(lat2))
                 * Math.pow(Math.sin(dLon / 2), 2);
        double c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
        return Math.round(EARTH_RADIUS_KM * c * 100.0) / 100.0;
    }

    public static boolean isPickupFeasible(double distanceKm, long minutesUntilExpiry) {
        int etaMinutes = (int) Math.ceil((distanceKm / AVERAGE_CITY_SPEED_KMH) * 60.0) + 10;
        return minutesUntilExpiry >= etaMinutes;
    }
}
